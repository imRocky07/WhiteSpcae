#WhiteSpace ⏱️

WhiteSpace is a simple and interactive Pomodoro productivity web application designed to help users stay focused while studying, coding, or working.

The application combines a Pomodoro timer with music controls, task tracking, and productivity-focused features in a clean and user-friendly interface.

## ✨ Features

- ⏱️ Pomodoro timer for focused work sessions
- 🔄 Work and break intervals
- 🎵 Built-in music player for background focus music
- 📋 Task management
- 📊 Basic productivity tracking
- 🎨 Clean and responsive user interface
- 🌙 Dark-themed productivity dashboard
- ⚡ Simple and fast browser-based experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio / HTML5 Audio APIs
- Git & GitHub
